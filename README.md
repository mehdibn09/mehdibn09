## Projets principaux

### TicketAssist — Agent de gestion des tickets IT

Agent intelligent consacré au tri et à l’orientation des demandes de support informatique.

**Objectif :** automatiser les premières étapes du traitement des tickets et faciliter leur prise en charge par les équipes concernées.

Fonctionnalités visées :
- Analyser le contenu des demandes.
- Classer les tickets par catégorie et identifier leur priorité.
- Orienter les demandes vers l’équipe adaptée.
- Générer une première réponse.
- Escalader les situations complexes.
